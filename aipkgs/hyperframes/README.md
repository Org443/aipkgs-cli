# Hyperframes

HeyGen's **HyperFrames** packaged as an AIpkgs box: 15 Claude Code skills for
turning HTML into rendered video. Covers compositions, runtime animation
adapters (GSAP, anime.js, Lottie, Three.js, WAAPI, CSS, TypeGPU), Tailwind
styling, captions/voiceovers and media handling, the HyperFrames CLI, the
registry, and website/Remotion → HyperFrames conversion.

## Skills

`hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `hyperframes-media`,
`website-to-hyperframes`, `remotion-to-hyperframes`, `contribute-catalog`,
`gsap`, `animejs`, `lottie`, `three`, `typegpu`, `waapi`, `css-animations`,
`tailwind`.
