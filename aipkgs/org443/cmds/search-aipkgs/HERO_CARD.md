# search-aipkgs

Search the AIpkgs registry and find the right package for your task.

**What it does**
- Searches packages by keyword, type, tags, and description
- Fetches full package details for top matches
- Recommends the best fit and explains why

**Package types**
- `cmd` — slash commands
- `skill` — reusable prompt libraries
- `rule` — always-on behavior rules
- `subagent` — specialist agents

**Usage:** `/search-aipkgs <what you want to do>`
